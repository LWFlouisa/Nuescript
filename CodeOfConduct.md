# Code Of Conduct
Recent changes have turned Github in a hostile working environment for Independant Game Designers.

## Hard Requirements ( Zero Tolerance )

Do Not Assume because we met before that you have permission to change or alter my software if you're not part of my open source team. Or change features without consulting me.

<b><i>Contribution</i></b> Do not make changes unless I have personally vouched for you. Anyone doing this will be banned from this repository. This includes unauthorized changes to code of conduct, which is not a valid contribution.

<b><i>Commercial</i></b> And Non Academic Uses Do not repackage and rebrand this software to attempt to compete with it and provide no attribution.

<b><i>Intellectual Property</i></b> Do not submit AI Slop as contributions, or steal from other developers when submitting code in pull requests or in the issues panel. Or any other format where user-submissions are taken. This includes stealing my webcomic assets to sell them back to me.

<b><i>Misuse Of Code Of Conduc</i></b> Do not leverage or misuse these terms of service to justify repository take over and theft. People that do that will be blocked and reported to github immediatly.

<b><i>Trans Issues</i></b> Do not leverage or weaponize trans issues either for in a way not representative, or in despisal of, trans issues. This repository is not about this topic. I place this as low lier because one time is a mistake, two times is a pattern of bigotry.

<b><i>Specific Design</i></b> Decisions If I make a specific design decision, do not attempt to overrule that decision by doing the opposite of what the intended scope is.

<b><i>False Accusation</i></b> Do not smear people's reputation as being vibe coders unless you can prove that in a court of law. Continuing to do so gets your ass removed from contributors.
